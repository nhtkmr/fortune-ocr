シリアル読み取りツール

応募券を並べて撮影すると、シリアルナンバーを読み取って登録ページの入力枠に自動で入れるブックマークレットです。

1. ブックマークレットをコピー

2. ブックマークに登録

文字で読む

Android（Chrome）

  1. このページで︙ →☆ でブックマークを追加
  2. ︙ →「ブックマーク」→ 追加したものを長押し →「編集」
  3. 名前を「シリアル読取」に、URLをコピーしたコードに置き換えて保存

iPhone（Safari）

  1. このページを開いたまま、共有ボタン →「ブックマークを追加」で保存（名前は「シリアル読取」など）
  2. ブックマーク一覧 →「編集」→ 今保存したブックマークをタップ
  3. URL欄の中身を全部消して、コピーしたコードを貼り付けて保存

3. 使い方

文字で読む
  1. 応募サイトにログインして「シリアルナンバー登録」ページを開く
  2. ブックマークレットを実行
    Android: アドレスバーに「シリアル読取」と入力し、候補に出るブックマークをタップ
    iPhone: ブックマーク一覧から「シリアル読取」をタップ
  3. 画面下にパネルが出たら「📷 撮影」。応募券をずらして重ね、シリアル部分が全部写るように撮る（1枚に複数枚OK）
  4. 読み取り結果を券と見比べて確認。間違いはその場で修正（黄色＝要確認、赤＝桁数が合わない）
  5. 「入力枠へ反映」→ ページ側の入力内容を確認して「シリアルナンバー登録」を押す
  6. 11件以上ある場合は、登録完了後にもう一度登録ページを開いて「入力枠へ反映」で残りを入れる

注意

  • 初回はOCRデータ（約40MB）をダウンロードします。Wi-Fi環境推奨。2回目以降はキャッシュされます。
  • 読み取りはすべてスマホ内で行われ、写真やシリアルが外部に送信されることはありません。
  • 登録ボタンは自動では押しません。登録失敗を繰り返すとアカウントが一時停止されるため、必ず目視で確認してください。
